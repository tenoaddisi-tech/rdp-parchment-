Browser extension

Chrome/Chromium Manifest V3 extension. Requires the local Windows app to be running at 127.0.0.1:8787.

Download extension ZIP
Install the extension
  1. Extract the extension ZIP to a folder.
  2. Open chrome://extensions in Chrome or Chromium.
  3. Enable Developer mode and choose Load unpacked, then select the extracted folder.
  4. Build and start the Windows app, then open the extension from the browser toolbar.
Build the Windows app

Extract the source ZIP, install CMake and a C++17 compiler (such as Visual Studio Build Tools), then run .\tools\package-windows-release.ps1 in PowerShell. Start Start RDRAND Lab.cmd from the generated portable bundle.

The local C++ app uses RDRAND to seed xoshiro256**, which is not a cryptographic generator. Do not use that app's output for passwords, keys, tokens, or nonces. The browser extension requests access only to the local app at 127.0.0.1:8787.

The interactive hosted demo uses the browser's Web Crypto API. The downloadable C++ app checks RDRAND support at runtime and performs hardware-seeded generation locally. The website does not access your CPU's RDRAND instruction.
