RDRAND Lab

A lightweight C++ app seeded with the CPU's RDRAND instruction, with a browser extension for quick access. Random generation happens on your own computer; this website does not generate or collect random values.

Windows app source

Build the local C++ app on Windows with CMake and a C++17 compiler. A prebuilt Windows executable is not available in this release.

Download source ZIP

Browser extension

Chrome/Chromium Manifest V3 extension. Requires the local Windows app to be running at 127.0.0.1:8787.

Download extension ZIP
Install the extension
  1. Extract the extension ZIP to a folder.
  2. Open chrome://extensions in Chrome or Chromium.
  3. Enable Developer mode and choose Load unpacked, then select the extracted folder.
  4. Build and start the Windows app, then open the extension from the browser toolbar.
Build the Windows app

Extract the source ZIP, install CMake and a C++17 compiler (such as Visual Studio Build Tools), then run .\tools\package-windows-release.ps1 in PowerShell. Start Start RDRAND Lab.cmd from the generated portable bundle.

Security note: xoshiro256** is not a cryptographic generator. Do not use its output for passwords, keys, tokens, or nonces. The extension requests access only to the local app at 127.0.0.1:8787.

RDRAND is checked for CPU support at runtime. Hardware/VM availability may vary. The public website serves download files only; the C++ backend and random generation run locally.
