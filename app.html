A note on security

Built to explore, not to protect secrets

The browser's Web Crypto API is intended for secure random bytes, but this page is an educational generator demo. The desktop app's xoshiro256** PRNG is explicitly non-cryptographic.

Do not use the desktop app for keys, passwords, tokens, or nonces. Generated demo values stay in this tab.

Browser demo: Web Crypto API · local desktop app: RDRAND-seeded xoshiro256** · bounded values use rejection sampling.
